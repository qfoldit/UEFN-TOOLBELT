# qFoldIT UEFN Toolbelt IP Boundary

This repository is an intentionally public runtime adapter surface. Its published source remains governed by the repository's applicable open-source license and attribution terms.

## Public boundary

The public Toolbelt contains generic UEFN automation, UAG adapter behavior, MCP-facing tooling and reusable runtime integration mechanisms that qFoldIT intentionally publishes.

## Private qFoldIT boundary

Do not place confidential customer workflows, private mission policies, protected scientific references, credentials, signing material or undisclosed commercial algorithms in this repository.

Proprietary extensions may be implemented in private qFoldIT repositories and connected through stable public adapter contracts.

## Scientific boundary

Runtime capabilities and gameplay interaction do not establish scientific validity. Scientific evidence remains authoritative in the configured qFoldIT scientific validation service.

## Provenance

Production releases should preserve commit SHA, author, review reference, release identifier, artifact hashes and the corresponding qFoldIT IP evidence registry version.

UEFN, Epic Games, Fortnite, user-generated content systems and third-party assets retain their respective intellectual-property and platform rights. This repository does not grant rights to third-party brands or assets.
