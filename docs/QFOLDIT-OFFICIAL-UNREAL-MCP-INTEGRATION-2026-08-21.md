# qFoldIT + Official Unreal MCP Integration — 2026-08-22

Epic's Unreal MCP is officially available in UEFN through Fortnite 42.00. It provides an embedded MCP server for agentic editor workflows including Verse, Scene Graph, Creative devices and play sessions.

## Migration rule

For supported low-level editor operations, prefer the official Unreal MCP. Retain qFoldIT tooling where it adds scientific semantics, composite mission operations, provenance, compliance, validation, model routing, or compatibility not supplied by the official layer.

## Valuation and rights classification

Epic/Unreal/UEFN technologies are third-party platform capabilities and MUST remain classified as external/platform IP in qFoldIT's IP registry.

External frontier-model capabilities are likewise vendor/external evidence. qFoldIT valuation attaches to the governed architecture around those capabilities rather than to third-party model or platform IP.
